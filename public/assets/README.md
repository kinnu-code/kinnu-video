# Assets

demo/       Everything the product demo uses (src/demo/assets.ts, testimonials.ts): app screenshots, voiceover, music, faces.
screens/    PNG screenshots at 3x DPR, 393x852 logical (1179x2556 px). Generated by `npm run capture`. Never hand-crop.
logos/      Official SVGs from each firm's brand page. No PNGs, no upscales.
broll/      Optional generative clips (Veo 3.1 / Runway) at 1080p or higher, 4 to 8 s, no UI or text in frame.
fonts/      Brand font files as woff2. Wire them in src/fonts.ts.
